# 配套开发文档说明

本目录中的 DOCX 与 PDF 文件是课程提交时生成的文档快照。

它们用于保留提交版本和排版结果，不保证随源码、Issue 或后续修复持续更新。

文档读取优先级：

1. 根目录 [`README.md`](../README.md)：当前项目定位、能力状态、限制和 Backlog 的事实来源。
2. 根目录 [`DEMO_GUIDE.md`](../DEMO_GUIDE.md)：当前推荐演示步骤和已知演示边界。
3. 本目录 DOCX/PDF：课程提交历史快照。

更新源码能力时，应优先同步根目录 README。只有准备重新提交课程材料时，才需要重新生成 DOCX/PDF。
